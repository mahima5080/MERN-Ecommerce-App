# Full-Stack MERN E-Commerce Web Application — Major Project (Week 4)

## 📌 Project Overview
This repository contains the **MERN Stack Week 4 Major Project**[cite: 79]. It is a full-featured **E-Commerce Web Application** featuring user authentication (JWT), a dynamic product catalog, cart management, and order placement with historical tracking[cite: 79].

---

## 🛠️ Architecture & Features[cite: 79]
* **User Authentication**: Registration, password hashing (`bcryptjs`), and session tokens (`jsonwebtoken`)[cite: 58, 79].
* **Product Catalog**: Automatic database seeding and RESTful product endpoints[cite: 79].
* **Shopping Cart**: Client-side state management for adding items and calculating cart totals[cite: 79].
* **Order Management**: Secure checkout saving user orders into MongoDB[cite: 79].
